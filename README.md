## Introduction

Anime Studio is a powerful software designed for creating anime-style animations. The **Subs and Dubs** tools enhance this experience by allowing users to add subtitles and voiceovers to their projects. This documentation aims to provide you with all the necessary information to make the most out of these features.

## Getting Started

To get started with the Subs and Dubs tools, you need to ensure you have the Anime Studio software installed. You can find the installation instructions in the [installation section](#installation).

Once you have the software ready, you can dive into creating your first subtitled or dubbed anime project. The tools are user-friendly and designed to streamline the process of adding text and audio to your animations.

## Installation

Follow these steps to install the Subs and Dubs tools:

1. **Download the Software**: Visit the [Releases](https://github.com/Rian-ryt/Anime_Studio_Subs-and-Dubs_Docs/releases) section to download the latest version.
2. **Run the Installer**: Once downloaded, run the installer and follow the on-screen instructions.
3. **Set Up the Environment**: Ensure that your system meets the requirements for running Anime Studio.
4. **Launch Anime Studio**: After installation, open the software to start using the Subs and Dubs tools.

## Usage

### Adding Subtitles

1. **Open Your Project**: Launch Anime Studio and open the project you want to work on.
2. **Select the Subtitle Tool**: Navigate to the tools panel and select the subtitle tool.
3. **Add Text**: Click on the area where you want to add subtitles and type your text.
4. **Adjust Timing**: Set the start and end times for your subtitles to sync with the audio.
5. **Style Your Text**: Customize the font, size, and color of your subtitles to fit your project’s aesthetic.

### Adding Dubs

1. **Open Your Project**: Launch Anime Studio and open your project.
2. **Select the Dub Tool**: Choose the dub tool from the tools panel.
3. **Record Audio**: Click the record button and speak your lines.
4. **Sync Audio**: Adjust the timing of your audio to match the animation.
5. **Fine-tune**: Use the editing tools to cut or extend audio clips as needed.

## Features

- **User-Friendly Interface**: The tools are designed for both beginners and advanced users.
- **Customizable Options**: Change fonts, colors, and styles for subtitles.
- **Audio Recording**: Directly record voiceovers within the software.
- **Timing Control**: Easily adjust the timing for both subtitles and audio.
- **Export Options**: Export your project in various formats for sharing.
